# Updated Portfolio Website

Modern React portfolio with smooth animations and a responsive layout.

## Features

- Animated sections (Framer Motion)
- Project showcase and skills
- Contact form with toast feedback
- Mobile-friendly navigation

## Tech stack

- **React 18** + **TypeScript**
- **Tailwind CSS**
- **Framer Motion**
- **React Router**
- **Vite**

## Getting started

```bash
npm install
npm run dev
```

```bash
npm run build
npm run preview
```
